# مولّد تصنيفات الصياد — تحديث 1.4.0

## ما الجديد

- زر **✚ جديد** يبدأ إنشاء تصنيف جديد دون إعادة تحميل الصفحة، مع رسالة تأكيد عند وجود عمل غير محفوظ.
- إزالة الكتابات الافتراضية من حقول الموضوع والسياق والاستبعادات؛ أصبحت الأمثلة تلميحات (placeholder). وعند التركيز على اسم تصنيف مولّد تلقائيًا، يُحدد النص لسهولة استبداله.
- قسم **04 · تجميع ملفات التصنيفات**: اختر ملفات JSON متعددة دفعة واحدة أو أضفها تباعًا، واحصل على ملف واحد قابل للاستيراد إلى «الصياد الباحث».
- عند تشابه أسماء التصنيفات، يمكنك دمج العبارات دون تكرار أو الاحتفاظ بنسخ مستقلة بأسماء مختلفة. لا يُحذف أي ملف أصلي.
- عند تعارض معرّفات التصنيفات، يُنشأ معرّف جديد للتصنيف القادم حفاظًا على جميع التصنيفات.
- دعم الوصف الاختياري للتصنيف، مع استخدام اسم التصنيف وصفًا افتراضيًا قصيرًا.
- معالجة علامات الهروب في وسوم `\#` داخل إجابات الذكاء الاصطناعي.

## التحديث في GitHub Pages

1. افتح مستودع `ensanbinadam/research-hunter-generator` على GitHub.
2. افتح ملف `index.html` واختر **Edit this file**.
3. استبدل كامل محتواه بمحتوى `index.html` الجديد في هذه الحزمة، أو ارفع الملف بديلًا عنه عبر GitHub.
4. احفظ التغيير في فرع `main`، ثم افتح الرابط العام وتحقق من ظهور قسم **04 · تجميع ملفات التصنيفات**.

> إذا كنت ترغب في الاحتفاظ بالإصدار القديم، نزّل ملف `index.html` الحالي قبل التحديث؛ سيبقى تاريخ GitHub مرجعًا للتغييرات أيضًا.

## تجميع الملفات عمليًا

1. افتح قسم **04 · تجميع ملفات التصنيفات**.
2. اختر ملفات `رياضيات.json` و`علوم.json` و`الصف-الثالث.json` وغيرها (يمكن الاختيار المتعدد).
3. راجع الأسماء والعدد النهائي، واختر طريقة معالجة التصنيفات المتكررة.
4. اضغط **تنزيل JSON موحّد لكل الملفات**.
5. في إضافة «الصياد الباحث»، **صدّر نسخة احتياطية من تصنيفاتك الحالية أولًا** إذا لم تكن ضمن الملفات التي جمعتها.
6. استورد الملف الموحد إلى «الصياد الباحث».

### تنبيه ضروري

استيراد ملف JSON إلى إصدار «الصياد الباحث» الحالي **يستبدل** التصنيفات الموجودة فيه. للحفاظ على جميع تصنيفاتك الموجودة، صدّر نسخة منها من الإضافة، **وأضف هذه النسخة ضمن ملفات التجميع** قبل إنشاء الملف النهائي. لا يكفي جمع ملفات جديدة وحدها للحفاظ على تصنيفات موجودة في الإضافة ولم تُضمّن في الملفات.

### قيود التوافق

- الحد الأقصى في الصياد الباحث الحالي: 50 تصنيفًا. إذا تجاوز ناتج الجمع هذا العدد، يتوقف تنزيل الملف مع رسالة واضحة.
- يدعم الملفات الصادرة بصيغتي `research-hunter-categories` أو `prompt-hunter-categories`، مع الاحتفاظ بالتقسيمات والمعرّفات الصحيحة.
- لا تُرفع ملفات JSON لخادم؛ تتم المعالجة والتنزيل محليًا في متصفحك.

## الفحص

اختُبرت الواجهة في Chromium، بما فيها زر «جديد»، وتوليد البرومبت، وفرز الوسوم، واستيراد ثلاثة ملفات، ودمج التصنيفات المتشابهة، ومنع تصدير أكثر من 50 تصنيفًا، وتنزيل ملف JSON متوافق.
