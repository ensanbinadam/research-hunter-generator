# مولّد تصنيفات الصياد | Hunter Category Generator

أداة ويب عربية مستقلة تُساعد مستخدمي إضافة **[الصياد الباحث](https://chromewebstore.google.com/detail/inleefjhamfghinhobgddfljgjcdpolp)** على إعداد تصنيفات بحث دقيقة لمنصة **X (تويتر)**، بالاستعانة بنموذج الذكاء الاصطناعي الذي يختارونه، ثم تصدير التصنيفات بصيغة JSON المتوافقة مع الإضافة.

> **لا تحتاج الأداة إلى مفتاح API أو حساب أو خادم خاص.** تعمل واجهتها وعمليات الفرز والدمج والتصدير داخل متصفح المستخدم.

## ما الذي تفعله الأداة؟

1. تبني برومبت تفصيليًا بناءً على موضوع البحث واللغة ونوع المصطلحات والقيود التي يحددها المستخدم.
2. تطلب من نموذج الذكاء تنظيم النتيجة تحت العناوين الثابتة التي يحتاجها المولّد:
   - `AR_PHRASES` — عبارات عربية.
   - `AR_HASHTAGS` — هاشتاقات عربية.
   - `EN_PHRASES` — عبارات إنجليزية.
   - `EN_HASHTAGS` — هاشتاقات إنجليزية.
3. بعد لصق الإجابة، تنقل المصطلحات إلى حاويات قابلة للمراجعة والتعديل والنسخ؛ وتتعامل مع الهاشتاقات التي يظهر قبلها رمز هروب مثل `\#`.
4. تسمح بتخصيص **اسم ووصف كل تصنيف**؛ وإذا تُرك الوصف فارغًا يُستخدم اسم التصنيف نفسه.
5. تُصدر ملف JSON للتصنيفات الجديدة فقط، أو تدمجها مع تصنيفات قديمة مستوردة من «الصياد الباحث».

## طريقة الاستخدام

1. افتح صفحة المولّد (`index.html` محليًا أو عبر GitHub Pages).
2. اكتب موضوع البحث، والتفاصيل الإضافية، وما تريد استبعاده.
3. اختر العربية أو الإنجليزية أو كلتيهما؛ ثم «عبارات» أو «هاشتاقات» أو «مزدوج».
4. اضغط **توليد البرومبت**، وانسخه إلى أداة الذكاء الاصطناعي المناسبة لك.
5. ألصق نتيجة الذكاء في حقل **إجابة الذكاء الاصطناعي**، ثم اضغط **توزيع الإجابة على الحاويات**.
6. راجع الكلمات والهاشتاقات وصحّح ما يلزم، ويمكنك تعديل أسماء التصنيفات وأوصافها.
7. اختر إحدى طريقتَي التصدير:
   - **دمج القديم + الجديد (موصى به):** صدّر نسخة تصنيفاتك الحالية من الإضافة، واستوردها في المولّد، ثم صدّر الملف الموحّد.
   - **الجديد فقط:** لا يتطلب نسخة قديمة، لكن استيراده في الإضافة **يستبدل جميع التصنيفات الحالية**.
8. افتح لوحة تحكم «الصياد الباحث» واستورد ملف JSON الناتج.

### تنبيه مهم قبل الاستيراد

**استيراد JSON في إصدار الصياد الباحث المستهدف يستبدل قائمة التصنيفات الموجودة، ولا يضيف إليها تلقائيًا.** لحفظ بياناتك، احتفظ بنسخة احتياطية واستخدم وضع الدمج. يُفضّل إنهاء جولة البحث الجارية قبل الاستيراد.

## التوافق والحدود

- صُمّم ملف التصدير ليتوافق مع **Research Hunter v1.3.0** وصيغته `research-hunter-categories`، الإصدار `2`.
- يدعم المولّد حدًا أقصى **50 تصنيفًا** في الملف المُصدّر، وفق حدود الإضافة المشار إليها.
- يراجع بعض أشكال الهاشتاقات وينظّمها، لكنه **لا يتحقق من انتشار الوسوم على منصة X ولا من صحة كل موضوع علميًا**.
- **المولّد لا يستدعي نموذجًا ذكيًا بنفسه**؛ ينشئ البرومبت فقط، والمستخدم ينقله إلى الخدمة التي يختارها.
- لا توجد مكتبات خارجية أو عملية بناء إلزامية؛ الواجهة في ملف HTML واحد يحتوي CSS وJavaScript.

## تشغيله محليًا أو نشره

افتح `index.html` مباشرة في متصفح حديث، أو ارفع الملفات إلى مستودع GitHub وفعّل GitHub Pages. الخطوات المفصلة في [PUBLISHING.md](PUBLISHING.md).

## الخصوصية

البرومبت والإجابات وملفات JSON تُعالج محليًا في الصفحة. لا يرسل المولّد محتوى النماذج أو الملفات إلى خادم خاص به. عند اختيار فتح خدمة خارجية للذكاء الاصطناعي وإرسال نص إليها بنفسك، تسري سياسة تلك الخدمة. اقرأ [PRIVACY.md](PRIVACY.md).
